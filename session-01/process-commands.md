### Commands

- `ps` or  `ps -ef` or `ps aux` &rarr; default process view
- <!-- .element class="fragment" -->
    `pstree` &rarr; tree view of processes
- <!-- .element class="fragment" -->
    `top` &rarr; interactive view, like a terminal task manager (exit with `q` )
- <!-- .element class="fragment" -->
    `htop` &rarr; prettier interactive view (exit with `q` )
- <!-- .element class="fragment" -->
    `ls /proc` &rarr; the file system representation of all processes (File API to the Linux kernel)

Please try all commands in your terminal <!-- .element class="fragment" -->


notes:
    - nobody types much in the terminal!!
    - there is a command history
    - arrow up/down
    - [Ctrl]+[r] searches [→] selects
    - [Ctrl]+[c] terminates a command
