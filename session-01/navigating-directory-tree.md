### Always Keep Moving<!-- .element class="c-pink" -->

the most important commands for the filesystem!

```bash
cd                          # change directory
ls                          # list directory
pwd                         # print working directory
mkdir ./new-dir             # creates a new directory
mv ./src.txt ./dest.txt     # moves/renames
cp ./src.txt ./dest2.txt    # copies
rm ./dest2.txt              # deletes
rm -r ./a-dir/              # deletes a directory, including files
rmdir ./another-dir/        # deletes an empty(!) directory
cat ./some-file.txt         # outputs content to terminal
reset                       # resets the terminal
```
