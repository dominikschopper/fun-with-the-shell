**the more ways you find, the sneakier you are!!!**

1. Create a file with the name `\` and delete it again!
1. Create a file with the name `/` and delete it again!
1. Create a file with the name `..` and delete it again!
1. Create a directory with the name `-f` (in words "MINUS" "f"!) and delete it again!
1. Create a directory with the name ` -r` (in words "SPACE" "MINUS" "r"!) and delete it again!
1. Create a file whose name is a space and delete it again!
1. Create a directory with the name `. ..` (in words "DOT" "SPACE" "DOT" "DOT"!) and delete it again!
