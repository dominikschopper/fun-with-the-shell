## Exercises on Navigation/Creating/Deleting

You are not allowed to type existing paths/file names. Always type only the next letters needed!


- Which directory are you currently in?
- Navigate to the `gallisches-dorf` directory
- Go back to the previous directory (check with `pwd`)
- Can you find a "shortcut command" for this?
- Go to the parent directory (check with `pwd`)
- Navigate to your home directory using an absolute path
- Copy the file `asterix.haus` to the `obelix` directory under the name `asterix-ferienhaus`
- Delete the file `asterix-ferienhaus` using the **absolute** path!
- Copy the directory `miraculix` with all its contents in the `gallisches-dorf` folder. The target directory should be named `zweiter-druide`. Also rename the new house file to `zweiter-druide.haus`
- Delete the directory that you just created
- Can you find a way to create the directory `methusalix` and the subdirectory `methusalix/scheune` with a single command?
- What does `ls -a` output show you?
- Delete `methusalix` and its subdirectories using `rmdir`
- Create a copy using the following command `sudo cp ./miraculix/miraculix.haus ./miraculix/2miraculix.haus`. What do you notice about the created files? What happens when you try to delete them with `rm -r`? Why?
