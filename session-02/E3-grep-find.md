## Grep Exercises

Preparation: run the command `sudo start-logging.sh`.

- how do I find all lines containing `ix` from the file `obelix.haus`
- how do I find all lines containing `as` from the file `obelix.haus`, regardless of uppercase or lowercase
- how do I find all files in my `$HOME` directory with grep that contain an `ix`
- how do I find all files in my `$HOME` directory with grep that contain an `As` (with and without case sensitivity)
- display all lines from the file `/var/log/fake-service.log` that
    - contain the string `OK`.
    - contain the string `proc`.
    - do NOT contain the string `ERR`.

## Find Exercises

Preparation: Your location should be your HOME directory. Create a directory `roemische-lager/SEISDRUM` (note the UPPERCASE!!)

The word "entries" here means "files" and "directories", "file" means an entry of type "f", "directory" means an entry of type "d"

- search from your current location for all entries named `miraculix.haus`
- search from your current location for all entries ending with `.zelt`
- search from your current location for all directories(!) containing `um`
- search from your current location for all directories(!) containing `um`, regardless of uppercase or lowercase
- search in the _entire filesystem_ for all files created 12 or more days ago
- search in the /var/log directory for all files modified less than 1 day ago
