### Aliases Exercises

- How do you display all aliases?
- Why is it better to write aliases in `.bashrc` and not in `.bash_profile`?
- Define an alias that instead of the command `pwd` simply outputs "I have no idea!".
- Please delete the alias again. Which methods do you know to do this?
- There was a security alias that was preset for normal users in SuSE Linux for a long time. The `rm` command (and `cp` and `mv`) was aliased so that `rm` would ask interactively before deleting a file. (The Windows feeling "Are you sure ..." in the Linux terminal `\o/` )
    - find out which option for `rm`, `cp` and `mv` makes them ask before proceeding
    - define aliases that instead of simply calling `rm` modify the call so that it asks first.
