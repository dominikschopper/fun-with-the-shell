## Environment Variables & Login Exercises

- Which environment variables do you know? (More than 3 gets bonus points!)
    - Where can you look up more?
- How can you display all environment variables?
- Define a new environment variable `FOO="Hello World"` and open a child shell with `bash`.
    What do you need to do so that the command `echo $FOO` outputs `"Hello World"` in the child shell?
- Think about this first: Can you change an environment variable after it's been set?<br/>
    What happens if you set the `PATH` variable to `/`?<br/>
    What can you do to undo this? (As always, there are multiple ways)
- Create a folder `scripts` in your home directory. Add this folder to your PATH variable. Make this change permanent, i.e. from now on this folder should be in `PATH` even after logging out and back in. Which steps are necessary?
- What is stored in your Bash history? The alias you entered or its substituted command?<br/>
    Test this and check it.
